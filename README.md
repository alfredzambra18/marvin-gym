# 🏋️ Marvin Gym - Control & Automatización

Sistema de gestión de atletas, control de accesos, pagos y progreso físico. Construido en Python con una interfaz moderna y oscura.

## ✨ Características
- **Seguridad:** Contraseñas encriptadas con PBKDF2 y salt.
- **Control de Acceso:** Búsqueda por cédula y validación de membresía.
- **Caja y Reportes:** Gráficos, exportación a Excel (CSV) y recibos en PDF.
- **Progreso:** Seguimiento de peso, altura e IMC con gráfico evolutivo.
- **Respaldos:** Copias de seguridad automáticas diarias.

## 🚀 Instalación

### Linux (Mint, Ubuntu, Debian)
1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta: `chmod +x install_linux.sh && ./install_linux.sh`
3. Busca **Marvin Gym** en tu menú de aplicaciones.

### Windows
1. Instala [Python 3](https://www.python.org/downloads/) (Asegúrate de marcar "Add Python to PATH").
2. Haz doble clic en `install_windows.bat`.
3. Abre el acceso directo **Marvin Gym** que aparecerá en tu escritorio.

## 🔐 Contraseña por defecto
Al abrir por primera vez, el sistema pedirá crear una nueva contraseña de administrador.
